# هوية التصميم المعتمدة (من «طاقتي» و«سَيْل»)

هذا هو التصميم المفضّل لحسين في كل تطبيقاته. المرجع الفعلي هو كود طاقتي: `Hussein199800/Car` في `src/main.js` (الدوال `renderHeader`، `render`، `viewMore`) و`src/theme.css`. عند أي اختلاف بين هذا الملف والكود، الكود هو المرجع.

## 1. الهيكل: أين أنا؟ (أهم قاعدة)
- **شريط علوي ثابت** شفاف ضبابي فوق كل الشاشات:
  - **في التبويبات الرئيسية**: الشعار واسم التطبيق في جهة، وفي الجهة الأخرى **كتلة حالة** (اسم العنصر الحالي مثل الجهاز أو الدفتر، وتحته سطر حالة صغير ونقطة ملوّنة: متصل، أو تنبيه، أو تجريبي)، ثم زر إجراء سريع (تحديث أو ما يناسب).
  - **في الصفحات الفرعية**: زر رجوع، ثم **عنوان الصفحة** في الوسط، ثم نقطة الحالة.
- **عنوان كبير عريض باسم التبويب** («الرئيسية»، «الحاسبة»، «المزيد»…) أعلى محتوى كل تبويب، حتى يعرف المستخدم أين هو دائماً. الصفحات الفرعية **لا** تكرر العنوان الكبير، ويكفيها عنوان الشريط.
- **شريط تبويبات سفلي عائم** بحواف دائرية (32)، تبويب نشط بخلفية أخضر خفيف، أيقونة 26 فوق نص صغير. خمسة تبويبات كحد أقصى، و«الحاسبة» تبويب مستقل عندما تفيد.

## 2. تبويب «المزيد»: كل شيء مقسّم ومنظّم
بالترتيب:
1. **بطاقة بطل (hero)** لحالة العنصر الرئيسي (في طاقتي: الإنفرتر وحالته)، قابلة للضغط.
2. **صف اختصارات** من 4 أزرار ملوّنة (أيقونة + كلمتان) لأكثر الأعمال استخداماً.
3. **مجموعات بعناوين أقسام** (`sec-h`)، كل مجموعة قائمة **بطاقات** فيها: أيقونة داخل مربع ملوّن (أخضر، وردي، سماوي، كهرماني، بنفسجي، رمادي)، ثم عنوان، ثم سطر فرعي يصف الحالة الحالية (مثل «ليلي · البطارية 200 أمبير ساعة»)، وشارة اختيارية مثل «جديد».
4. زر خطر عريض في الأسفل (خروج أو ما يماثله).
5. تذييل صغير: «اسم التطبيق · الإصدار X».

## 4. السلوك
- بطاقات قصيرة تفتح صفحات فرعية قصيرة، بدل صفحات طويلة مزدحمة.
- كل حالة بنص وأيقونة مع اللون.
- الأرقام والتواريخ معزولة الاتجاه داخل النص العربي.
- الوضع التجريبي واضح في الشريط العلوي.

## 5. المساعدة والفهم (من «سَيْل»: `Hussein199800/download_video`، `src/views/guide.js` و`more.js` و`errors.js`)
- «المزيد» بثلاثة أقسام فرعية: الإعدادات أو الدفتر، **المساعدة**، **عن التطبيق**.
- الشرح مجموعات بعناوين، وكل بند يُفتح بلمسة (خطوات مرقّمة أو فقرات قصيرة)، وآخر مجموعة «حل المشكلات».
- جولة تعريفية للمستخدم الجديد، و«ما الجديد» بعد كل تحديث، وصفحة لكل الإصدارات.
- كل خطأ له سبب وحل بالعربية وزر الإجراء المناسب.
- التقارير المطبوعة رسمية وواضحة: ترويسة، ورقم، وصندوق معلومات، وملخّص بالبطاقات، واعتماد.
